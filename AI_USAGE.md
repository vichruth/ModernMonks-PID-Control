# AI Usage Disclosure

In accordance with the assignment guidelines, AI assistance (Antigravity / Gemini) was used during this project as an interactive pair-programming partner:

- **What AI was used for:**
  - Scaffolding repository structure, boilerplate code, and Matplotlib plotting templates.
  - Reviewing derivation steps and cross-checking theoretical formulas against simulation results.
  - Formatting tables and documentation templates.

- **What was verified independently:**
  - All physics and mathematical derivations (transfer functions, damping ratios, theoretical steady-state errors, Ziegler-Nichols critical gains).
  - Implementation of semi-implicit Euler integration, custom PID controller logic, anti-windup clamping, and low-pass filter equations without third-party control libraries.
  - Verification of simulation outputs against theoretical predictions before generating report figures.
