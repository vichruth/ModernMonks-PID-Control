# Prediction Log: Interview What-If Exercises

Use this log to practice before the 30-minute technical interview.
For each hypothetical parameter alteration below, write down your predicted outcome in the **My Prediction** column **BEFORE** running the simulation. Then check your intuition against the **Simulated Result** and internalize the physical mechanism in **Why**.

Baseline reference system: $m = 1.0\text{ kg}, c = 10.0\text{ N}\cdot\text{s/m}, k = 20.0\text{ N/m}$, Setpoint $r = 1.0\text{ m}$.
Baseline gains: $K_p = 300\text{ N/m}, K_i = 300\text{ N/(m}\cdot\text{s)}, K_d = 30\text{ N}\cdot\text{s/m}$ (clamping anti-windup, D on measurement, $T = 15.0\text{ s}$).
Baseline performance: $\text{Overshoot} = 4.27\%$, $\text{Settling Time} = 1.422\text{ s}$, $\text{Rise Time} = 0.206\text{ s}$, $\text{Peak Force} = 300.3\text{ N}$.
